# 마이폴학교 시뮬레이터

충북 괴산 청천의 마이폴학교를 3D로 만든 학교 시뮬레이터예요.
학교를 둘러보고, 선생님과 이야기하고, 마음껏 부수고, 보스전과 폴탈(마이폴 탈출)에 도전해 보세요.

**플레이:** https://pyeonjihwan28-boop.github.io/mypaul-simulator/

## 같이 부수기 (멀티플레이) · 채팅
- **메인 메뉴 채팅창**: 첫 화면 오른쪽 아래(휴대폰은 아래쪽)에서 지금 접속한 모두와 채팅해요. 이름도 거기서 바꿀 수 있어요.
- **게임 중 채팅창**: 왼쪽 아래에 늘 보여요. Enter 또는 T로 입력하고, 입력 중 Tab으로 `전체` ↔ `방` 채팅을 바꿔요.
- **방 만들기**: 같이 부수기 → 방 이름을 정하고 `모두 접속 가능` 또는 `비밀번호`를 골라 만들어요.
  - 비밀번호 방은 비밀번호를 아는 사람만 들어올 수 있어요. 비밀번호 자체는 어디에도 보내지 않고, 연결은 그 비밀번호로 암호화돼요.
- 한 방에 최대 4명이고, 폭발·파괴·학교 다시 짓기가 함께 맞춰져요. 아무도 없는 방은 목록에서 사라져요.
- **같이 보스전**: 같은 방의 누가 보스전 중이면 화면 위에 보스 이름·레벨·인원이 떠요. `J`(또는 합류 버튼)로 들어가서 보스 체력을 함께 깎아요. 쓰러지면 15초 뒤 부활하고, 함께 싸우는 사람이 모두 쓰러져야 실패예요. 실패한 뒤 각자 "다시 시도"를 누르면 같은 보스전에서 다시 만나요.
- **보스 레벨 공유**: 같은 서버·방 사람이 보스를 잡으면 그 보스 레벨이 모두에게 함께 올라가요.
- **자동 업데이트**: 새 버전이 나오면 모두에게 알림이 뜨고, 저장한 뒤 자동으로 새로고침해서 하던 서버로 돌아와요.
- 친구에게 위 링크만 보내면 돼요. 로그인은 필요 없어요. 브라우저끼리 직접 연결해서 몇 초 걸릴 수 있고, 일부 학교·회사 와이파이에서는 막힐 수 있어요.

## 보스 · 능력치
- **보스 레벨**: 같은 보스를 잡을 때마다 그 보스만 1레벨씩 강해져요 (체력·공격력·속도·투사체 증가). 이겨도 선생님은 사라지지 않아서 계속 다시 도전할 수 있어요. 이름표 옆 색깔 배지로 레벨이 보여요 (초록→파랑→노랑→주황→빨강→보라).
- **보스마다 다른 필살기**: 이상문 쌤 수학 시험(정답 원 안에 서기) · 육민정 쌤 대걸레 휘두르기(점프) · 체육쌤 튕기는 피구공 · 교장선생님 번개 조회 · 교감선생님 초대형 결재 도장 · 박재현 쌤 레이저 그리드 · 현지우 쌤 논문 회오리(빨아들임) · 김광호 쌤 학생 돌격대 · 상담선생님 혼란의 하트(방향 반대) · 수탉 알 폭탄 부화 · 강아지 우다다 질주 등. 보스마다 별명과 아레나 색도 달라요.
- **보스**: 3페이즈(2페이즈 탄막, 광폭화 때 분신 소환·돌진 3연속·따라오는 투사체). 등장 연출, 체력바의 페이즈 눈금, 데미지 숫자, 결과 화면(보상·걸린 시간·같이 싸운 사람 기여도)이 있어요.
- **능력치가 실제로 영향**: 학업=보스 피해, 집중력=무기 재사용, 체력=보스전 체력·달리기, 스트레스=받는 피해(낮을수록 좋음), 프로젝트=폭발 범위, 평판=받는 피해 감소·호감도 보너스.
- **호감도 → 능력치**: 선생님마다 올려 주는 능력치가 있고, 호감도 60·70·80·90·100마다 큰 보너스. 친한 선생님은 보스전에서 살살 해 줘요.
- **레벨 업**: 대화·보스전 승리·학교 부수기로 경험치 → 레벨이 오르면 화면에 LEVEL UP이 뜨고 능력치 포인트 4개 + 코인을 받아요. 메뉴 → 능력치에서 원하는 능력치에 직접 찍어요 (1포인트 = +2, 스트레스는 −2).

## 무기 상점 · 코인
- `B` 키, 메뉴의 `무기 상점`, 또는 1층 매점 계산대에서 `E`로 열어요. 상점이 열리면 마우스 고정이 풀려서 클릭으로 바로 살 수 있어요.
- 코인: 보스 격파 · 선생님과 대화 · 학교 부수기 · 레벨 업 · 튜토리얼 완료.
- **보스 레벨에 따른 코인**: 이기면 Lv.1 200 · Lv.2 360 · Lv.3 560 · Lv.4 820 · Lv.5 1,120 · Lv.10 3,400 (개·수탉은 60%). 잡을 때마다 그 보스 레벨이 +1 되니까 다음 판은 더 많이 받아요. 지면 깎은 체력만큼 일부(최대 30%)를 받아요.
  - 받을 코인은 선생님 머리 위 이름표, 메뉴 → 선생님, 보스 등장 화면, 보스 체력바, 같이 보스전 합류 목록에 표시돼요. 이기면 코인이 쏟아져서 나에게 날아와요.
- 무기 (가격순): 샷건 300 · 화염방사기 500 · 미니건 700 · 부메랑 800 · 유도 미사일 900 · 얼음총 900 · 종이비행기 편대 1000 · 번개총 1100 · 레일건 1200 · 클러스터 폭탄 1300 · 중력 해머 1400 · 블랙홀 수류탄 · 초대형 폭탄 · 궤도 레이저 3500. 산 무기는 빈 칸에 들어가고 바로 장착돼요.
  - 레일건: 벽을 뚫고 일직선 저격 (보스 한 방 피해 최고) · 번개총: 누르고 있으면 지그재그 번개 연사 · 클러스터 폭탄: 터지면 작은 폭탄 6개로 갈라짐 · 종이비행기 편대: 5대가 선생님·보스를 알아서 쫓아감 · 궤도 레이저: 조준한 곳에 하늘에서 레이저가 8번 내리꽂힘 · 부메랑: 날아갔다 돌아오며 길목을 다 부숨 · 얼음총: 맞은 보스가 2초 동안 느려짐 · 중력 해머: 바로 앞 넓은 범위 충격파.
- **무기 특성**: 상점의 `특성` 탭에서 무기마다 **기본 특성 + 특성 1개**를 더 달 수 있어요 (예: 바주카포에 유도). 다른 특성으로 바꾸면 새 값을 내고, 빼기는 무료. 무기 칸에 특성 아이콘이 붙어요.
  - 유도 400 (조준이 선생님·보스에게 붙고 미사일·수류탄이 따라감) · 관통 450 (뚫고 뒤까지) · 분열 600 (작은 폭탄 3개) · 다중 발사 700 (양옆 1발씩, 옆 발 피해 50%) · 속사 500 (재사용 −30%) · 거대화 600 (폭발 범위 +40%, 보스 피해 +25%) · 빙결 500 (보스 2초 느리게) · 화염 550 (3초 불길, 보스 지속 피해) · 연쇄 번개 600 (근처 선생님·보스로 번개 2줄기) · 흡혈 500 (보스 피해의 8% 회복).
  - 원래 그 성질을 가진 무기는 기본 특성으로 들어 있어요 (유도 미사일·종이비행기 = 유도, 레일건·레이저 캐논 = 관통, 클러스터 = 분열, 샷건 = 다중 발사, 미니건 = 속사, 초대형 폭탄 = 거대화, 얼음총 = 빙결, 화염방사기 = 화염, 번개총 = 연쇄 번개). 연사 무기는 분열·빙결·화염·연쇄 번개가 가끔씩 터져요.
- **무기 강화**: 상점의 `무기 강화` 탭에서 코인으로 +1 ~ +10. 한 단계마다 보스 피해 +10% · 폭발 범위 +3% · 재사용 시간 −3%. +3부터 성공 확률이 낮아지고(최저 30%), 실패해도 단계는 떨어지지 않아요.

## PVP 경기장 (농구장)
- 같이 부수기 서버·방에서 **농구장**(서쪽 입구에 간판)에 2명 이상 들어가면 시작해요. 메뉴의 `PVP 경기장 가기`로 바로 갈 수 있어요.
- **무기 투표** 15초 (`P`: 투표판) → 가장 많이 받은 무기 **하나로 모두 똑같이** 싸워요. 같은 표면 그중에서 무작위, 모두 고르면 2초 뒤 바로 시작.
- **강화 +5 고정** · 경기 동안 내 강화·능력치·특성은 쓰지 않아요 · 체력 100 · 한 번에 최대 60 피해라서 어떤 무기도 한 방에 끝나지 않아요.
- 라운드마다 마지막까지 남은 사람이 1점 (90초가 지나면 체력이 더 많은 사람), **3점 먼저** 이기면 최종 승리. 라운드 승리 +20 · 최종 승리 +100 코인.
- 경기 중에는 농구장 밖으로 못 나가고 상점·가방을 못 열어요. 늦게 온 사람은 관전하다가 다음 경기에 같이 해요. 경기가 끝나면 원래 무기로 돌아와요.

## 처음 오면 이름 정하기 · 튜토리얼
- 처음 들어오면 친구들에게 보일 이름을 먼저 정해요 (최대 12글자, 메인 화면 채팅창에서 다시 바꿀 수 있어요).
- 이 브라우저로 처음 게임에 들어오면 걷기·둘러보기·달리기·웅크리기·무기·대화·지도 순서로 안내해요. 직접 해 보면 자동으로 넘어가고, 설정에서 다시 볼 수 있어요.

## 조작
| 동작 | 키 |
| --- | --- |
| 이동 / 달리기 / 점프 | WASD / Shift 또는 Ctrl / Space |
| 시점 | 마우스 이동 — 바로 따라가요. 게임 화면을 누르면 마우스 고정 (ESC: 메뉴). 캐릭터는 1인칭·3인칭 모두 마우스 방향을 바라봐요 |
| 날기 / 내려오기 | ↑ / ↓ |
| 무기 / 발사 | 1~0 · Q(다음 무기) / 좌클릭 |
| 상호작용 · 인벤토리 · 지도 · 메뉴 | E · Tab · M · ESC |
| 채팅 (전체 ↔ 방) | Enter 또는 T (입력 중 Tab) |
| 1인칭 ↔ 3인칭 (기본 1인칭) | V · 휠을 끝까지 당기기/밀기 |
| 웅크리기 | C 누르고 있기 (휴대폰은 버튼) |
| 무기 상점 | B · 매점 계산대에서 E |
| 같이 보스전 합류 | J (친구가 보스전 중일 때) |
| PVP 무기 투표판 | P (농구장 안에서) |
| 위·하늘 보기 | 마우스를 위로 (3인칭에서도 하늘까지) |

## 성능 자동 최적화
- 설정 → 그래픽 품질 `자동`(기본): 그래픽 카드·CPU 코어·메모리·화면 크기로 처음 품질을 고르고, 게임 중에는 실제 FPS를 보고 해상도(50~100%)와 품질 단계를 계속 맞춰요.
- 느린 컴퓨터에서는 불꽃·연기 파티클, 날아가는 조각 수, 그림자 다시 그리기 횟수를 줄여요. 설정에서 FPS 표시를 켤 수 있어요.
