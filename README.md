# 마이폴학교 시뮬레이터

충북 괴산 청천의 마이폴학교를 3D로 만든 학교 시뮬레이터예요.
학교를 둘러보고, 선생님과 이야기하고, 마음껏 부수고, 보스전과 폴탈(마이폴 탈출)에 도전해 보세요.

**플레이:** https://pyeonjihwan28-boop.github.io/mypaul-simulator/

## 같이 부수기 (멀티플레이)
- 타이틀이나 메뉴에서 **같이 부수기**를 누르고 서버 1~6 중 하나에 들어가요.
- 친구에게 위 링크를 보내고 **같은 서버 번호**로 들어오라고 하면 돼요. 로그인은 필요 없어요.
- 한 서버에 최대 4명이고, 폭발·파괴·학교 다시 짓기가 함께 맞춰져요. 보스전은 각자 따로 해요.
- 전체 채팅(메뉴)과 서버 채팅(게임 중 Enter 또는 T), 지금 접속자 수가 보여요. 오프라인이 된 사람은 목록에서 자동으로 빠져요.
- 브라우저끼리 직접 연결해서 몇 초 걸릴 수 있어요. 일부 학교·회사 와이파이에서는 연결이 막힐 수 있어요.

## 조작
| 동작 | 키 |
| --- | --- |
| 이동 / 달리기 / 점프 | WASD / Shift / Space |
| 시점 | 마우스 이동 (클릭하면 고정, ESC로 해제), ←→, 휠 |
| 날기 / 내려오기 | ↑ / ↓ |
| 무기 / 발사 | 1~0 / 좌클릭 |
| 상호작용 · 인벤토리 · 지도 · 메뉴 | E · Tab · M · ESC |

## 사용한 오픈소스 (모두 MIT 라이선스)
- [three.js](https://github.com/mrdoob/three.js) r169 — 3D 렌더링 (Sky, GTAO, Bloom, SMAA)
- [EZ-Tree](https://github.com/dgreenheck/ez-tree) 1.1.0 — 절차적 나무 생성
- [Trystero](https://github.com/dmotz/trystero) 0.26 — 같이 부수기 (WebRTC P2P)

학교 정보: 나무위키 '마이폴학교', 마이폴학교 공식 홈페이지(mypaul.org)
