# 마이폴학교 시뮬레이터

충북 괴산 청천의 마이폴학교를 3D로 만든 학교 시뮬레이터예요.
학교를 둘러보고, 선생님과 이야기하고, 마음껏 부수고, 보스전과 폴탈(마이폴 탈출)에 도전해 보세요.

**플레이:** https://pyeonjihwan28-boop.github.io/mypaul-simulator/

## 같이 부수기 (멀티플레이) · 채팅
- **메인 메뉴 채팅창**: 첫 화면 오른쪽 아래(휴대폰은 아래쪽)에서 지금 접속한 모두와 채팅해요. 이름도 거기서 바꿀 수 있어요.
- **게임 중 채팅창**: 왼쪽 아래에 늘 보여요. Enter 또는 T로 입력하고, 입력 중 Tab으로 `전체` ↔ `방` 채팅을 바꿔요.
- **방 만들기**: 같이 부수기 → 방 이름을 정하고 `모두 접속 가능` 또는 `비밀번호`를 골라 만들어요.
  - 비밀번호 방은 비밀번호를 아는 사람만 들어올 수 있어요. 비밀번호 자체는 어디에도 보내지 않고, 연결은 그 비밀번호로 암호화돼요.
- 한 방에 최대 4명이고, 폭발·파괴·학교 다시 짓기가 함께 맞춰져요. 아무도 없는 방은 목록에서 사라져요.
- **같이 보스전**: 같은 방의 누가 보스전 중이면 화면 위에 보스 이름·레벨·인원이 떠요. `J`(또는 합류 버튼)로 들어가서 보스 체력을 함께 깎아요. 쓰러지면 15초 뒤 부활하고, 함께 싸우는 사람이 모두 쓰러져야 실패예요.
- **1대1 PVP**: 같은 방에서 농구장에 둘이 들어가면 3·2·1 카운트다운 뒤 대결! 3번 먼저 이기면 승리 (세 번째 사람부터는 관전).
- **보스 레벨 공유**: 같은 서버·방 사람이 보스를 잡으면 그 보스 레벨이 모두에게 함께 올라가요.
- **자동 업데이트**: 새 버전이 나오면 모두에게 알림이 뜨고, 저장한 뒤 자동으로 새로고침해서 하던 서버로 돌아와요.
- 친구에게 위 링크만 보내면 돼요. 로그인은 필요 없어요. 브라우저끼리 직접 연결해서 몇 초 걸릴 수 있고, 일부 학교·회사 와이파이에서는 막힐 수 있어요.

## 보스 · 능력치
- **보스 레벨**: 같은 보스를 잡을 때마다 그 보스만 1레벨씩 강해져요 (체력·공격력·속도·투사체 증가). 이겨도 선생님은 사라지지 않아서 계속 다시 도전할 수 있어요. 이름표 옆 색깔 배지로 레벨이 보여요 (초록→파랑→노랑→주황→빨강→보라).
- **보스**: 3페이즈(2페이즈 탄막, 광폭화 때 분신 소환·돌진 3연속·따라오는 투사체).
- **능력치가 실제로 영향**: 학업=보스 피해, 집중력=무기 재사용, 체력=보스전 체력·달리기, 스트레스=받는 피해(낮을수록 좋음), 프로젝트=폭발 범위, 평판=받는 피해 감소·호감도 보너스.
- **호감도 → 능력치**: 선생님마다 올려 주는 능력치가 있고, 호감도 60·70·80·90·100마다 큰 보너스. 친한 선생님은 보스전에서 살살 해 줘요.
- **레벨**: 대화·보스전 승리·학교 부수기로 경험치 → 레벨 업하면 능력치가 전부 올라요.

## 무기 상점 · 코인
- `B` 키, 메뉴의 `무기 상점`, 또는 1층 매점 계산대에서 `E`로 열어요. 상점이 열리면 마우스 고정이 풀려서 클릭으로 바로 살 수 있어요.
- 코인: 보스 격파(레벨이 높을수록 많이) · 선생님과 대화 · 학교 부수기 · 레벨 업 · PVP 승리 · 튜토리얼 완료.
- 새 무기: 샷건 · 화염방사기 · 미니건 · 유도 미사일 · 블랙홀 수류탄 · 초대형 폭탄. 산 무기는 빈 칸에 들어가고 바로 장착돼요.

## 처음 오면 튜토리얼
- 이 브라우저로 처음 게임에 들어오면 걷기·둘러보기·달리기·웅크리기·무기·대화·지도 순서로 안내해요. 직접 해 보면 자동으로 넘어가고, 설정에서 다시 볼 수 있어요.

## 조작
| 동작 | 키 |
| --- | --- |
| 이동 / 달리기 / 점프 | WASD / Shift 또는 Ctrl / Space |
| 시점 | 마우스 이동 (클릭하면 고정, ESC로 해제), ←→, 휠 |
| 날기 / 내려오기 | ↑ / ↓ |
| 무기 / 발사 | 1~0 / 좌클릭 |
| 상호작용 · 인벤토리 · 지도 · 메뉴 | E · Tab · M · ESC |
| 채팅 (전체 ↔ 방) | Enter 또는 T (입력 중 Tab) |
| 1인칭 ↔ 3인칭 | V · 휠을 끝까지 당기기/밀기 |
| 웅크리기 | C 누르고 있기 (휴대폰은 버튼) |
| 무기 상점 | B · 매점 계산대에서 E |
| 같이 보스전 합류 | J (친구가 보스전 중일 때) |
| 위·하늘 보기 | 마우스를 위로 (3인칭에서도 하늘까지) |
